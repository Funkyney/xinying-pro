# 心影Pro 使用手册

心影Pro（AgentLab Pro）是一体化轻量桌面工作台。它保留心影官方的登录、审核、生成、额度和结果能力，把空间、对话、参考素材、虚拟人像、任务与原片下载整理到一个更直接的界面中。

## 产品特点

- 一个项目贯穿素材整理、人物授权、提示词、参数、批量生成、任务进度和结果审阅。
- 图片、视频、音频与心影已授权虚拟人像统一编号，可自由穿插和拖动排序；提交时自动换算心影实际编号。
- 可选择既有心影对话继续生成，也可明确新建对话，方便使用“复用并编辑”。
- 有人物的图片或视频可按合规流程上传为虚拟人像；审核、失败和人工处理状态都进入任务中心。
- 结果库区分“我的生成”和“项目素材库”，支持拖动多选、快速标记、原片下载和再次生成。
- Codex 扩展可把定稿提示词、电脑素材、人物授权与生成条数交给心影Pro自动执行，并在全部任务显示“生成中”后结束自动流程。
- 日间/夜间模式一键切换并自动记忆；页面和视频采用按需加载，减少无意义的后台刷新与网络占用。

## 安装、登录与更新

### Windows

运行 GitHub Release 中的 `Xinying-Director-*-x64.exe`。安装完成后从桌面“心影Pro”快捷方式启动。

### macOS

优先安装 Release 中的 DMG。未完成 Apple Developer ID 签名的版本，首次打开可能需要在“系统设置 → 隐私与安全性”中允许。应用内自动更新只有在安装包完成 Developer ID 签名和 Apple 公证后才能稳定工作；否则下载新版 DMG 覆盖安装。

### 飞书登录

1. 打开心影Pro，进入“原网页模式”或点击左下角登录按钮。
2. 使用自己的飞书扫码并在手机确认。
3. 登录信息保存在本机独立的 Electron 会话中，不进入项目数据库，也不会交给 Codex。

顶部“检查更新”会读取公开 GitHub Releases。发现新版后先下载，完成后点击“重启安装”。

## 推荐工作流

### 1. 选择空间、项目与对话

进入“空间与项目”，点击“同步心影”。空间/项目同步读取心影页面已经返回的目录响应，通常只需数秒。

选择项目后再选择：

- 已有对话：后续生成继续追加到该对话，可以复用上一条。
- 新建对话：在同一心影项目下开启一条全新的生成会话。

卡片上的“心影当前”只是心影网页当前上下文；“已绑定对话”才表示心影Pro后续提交会继续使用这条会话。

### 2. 整理参考素材

在“生成工作台”中可以：

- 上传图片、视频和音频；上传后同时进入本机共享素材库。
- 点击共享库中的素材，把它加入当前项目；再次点击即可移出。
- 点击已授权虚拟人像，把它加入上方创作顺序。
- 拖动任何素材卡片自由排序。不同媒体分别显示 `@图N`、`@视频N`、`@音频N`。
- 替换本地素材时编号保持；删除中间素材后，同类型后续编号自动前移。

Seedance 2.5 当前配置上限为 30 图、10 视频、10 音频且合计最多 50 项；实际可用能力以心影当前页面为准。

### 3. 人物素材授权

凡是包含可见真人或虚拟人物的图片、视频，都应走“虚拟人像”授权，不要作为普通参考素材直接提交。

首次使用需确认原创、权利和自动授权声明。之后卡片会直接显示“授权中 / 已授权 / 需人工处理 / 失败”。完整同步虚拟人像库需要滚动读取大量心影卡片；上千条角色可能需要几十秒，期间已有本地缓存仍可浏览，右下角会显示真实操作状态。

### 4. 设置提示词与参数

填写提示词，选择 Seedance 2.5 或 2.0、生成模式、画幅、时长、分辨率和声音。提示词支持 `@图1`、`@图一`、全角 `＠图一` 和“参考图三”等写法。

点击“预览提交”先检查：

- 最终素材编号和提示词引用是否一致；
- 人物素材是否全部通过授权；
- 参数是否在当前模型范围内；
- 生成条数是否正确（1–20）。

确认后任务进入本地队列。心影接受并显示“生成中”即代表自动提交完成，不会为了等待成片长期占用 Codex。

### 5. 管理任务

“任务队列”显示提交、生成、完成、失败和人工处理状态，以及心影任务号、进度、最近查询时间与事件记录。

- “同步状态”只查询任务，不会重复生成。
- 登录、实名、验证码、支付确认或页面变化会暂停为“需要人工处理”。
- 已结束记录可批量清理；活动任务不会被任务记录清理误删。

### 6. 审片、复用与下载

“结果库”中：

- “我的生成”包含可复用的个人会话结果；“项目素材库”包含团队可见素材。
- 鼠标左键拖动可多选；悬停卡片后按 `1` 可快速标记。
- 视频只在悬停或打开查看器时加载，进入结果库不会同时预加载几十条视频。
- “下载原片”保存心影原视频/原图，不保存网页预览。默认打开系统“下载”目录。
- 文件名按项目命名：`项目名-年月日-时分秒.ext`；批量下载再追加三位序号，已有同名文件不会被静默覆盖。
- 个人视频可点击“复用并编辑”，修改提示词和参数后提交 1–20 条。

## Codex 自动生成

1. 在“Codex扩展”点击“安装到 Codex”。
2. 新建 Codex 任务或重启 Codex。
3. 完成 Seedance 提示词后说：“用心影Pro生成 3 条”。

Codex 会检查素材路径和顺序；带人物的图片、视频先进入虚拟人像审核，通过后原位替换；随后提交指定条数。任务全部显示“生成中”后流程即成功结束。只有用户另外要求时，Codex 才继续同步或下载结果。

## 日间与夜间模式

顶部月亮/太阳按钮用于切换主题。设置保存在本机，重启应用后仍保持。夜间模式不会改变心影原网页自身的主题。

## 常见问题

### 空间与项目同步失败

先确认左下角显示“心影已连接”，再进入“原网页模式”看是否出现登录、验证码或官方错误。一次只执行一个心影网页操作；后续点击会进入队列，不需要连续重复点击。

### 虚拟人像一直显示“授权中”

进入“任务队列”查看对应人像审核任务的事件和人工处理原因，再点击“同步状态”。不要重复上传同一素材；心影Pro会复用已有活动任务。

### 程序提示 SQLite 或数据异常

退出心影Pro后先备份 `%APPDATA%\xinying-director`。开发/诊断环境可执行：

```powershell
xinying doctor
```

`databaseHealth` 应为 `ok`。不要手工删除 `xinying.sqlite3-wal` 或 `xinying.sqlite3-shm`。

### 更新后没有自动重启

等待顶部显示“新版已下载”，再点击“重启安装”。若仍无反应，完全退出心影Pro后运行已下载的新安装包；项目、素材和登录会话默认保留。

## 数据与安全边界

- 本地项目、素材副本、任务和结果索引默认位于 `%APPDATA%\xinying-director`。
- 删除项目只删除心影Pro保存的本地副本，不删除电脑原文件；心影网页中的外部删除会再次确认。
- 心影Pro不会绕过扫码、审核、实名、验证码、付费、额度或内容安全限制。
- 飞书 Cookie、Token、二维码和密码不会写入 SQLite、CLI 输出或 GitHub 仓库。
