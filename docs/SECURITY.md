# 安全与隐私

- 心影官方页面运行在隔离的 `persist:xinying-platform` Electron 会话中。
- 飞书密码、二维码内容、Cookie、Token 和浏览器配置不会写入应用数据库或 CLI 输出。
- 渲染进程启用 Electron 沙箱和上下文隔离并关闭 Node.js 集成；沙箱预加载脚本为单文件 IPC 白名单，本地文件只允许通过受控协议读取 SQLite 中已登记的参考素材、人像素材和结果路径。
- Playwright CDP 仅监听 `127.0.0.1`，应用使用单实例锁避免端口冲突。
- 内嵌外部导航只允许 HTTPS 白名单；系统浏览器只接收 HTTP/HTTPS 链接，拒绝 `file:`、`javascript:` 和自定义协议。
- 用户选择的参考素材会复制到本机应用数据目录，便于保持项目可重复执行。删除项目会删除这些副本，不删除原始文件。
- 生成入队时会再复制一份任务专属参考图快照并核对 SHA-256，防止排队后修改项目素材导致任务内容漂移。
- 结果 URL 回退下载只接受 HTTPS；“另存为”只复制结果，不改变结果库受管主文件。
- 虚拟人像素材提交前要求用户在 APP 明确确认与心影一致的原创、权利和非自然人相似性声明；确认可保存在本机，随后由适配器代勾选心影承诺并提交。声明未确认、字段无法回读、审核拒绝、实名、验证码和付费仍由用户处理。
- 心影共享虚拟人像的批量删除只允许选择官方页面明确显示删除入口的角色。APP 在执行前展示目标空间、数量和名称，并要求再次勾选不可恢复确认；适配器逐项核对心影官方删除提示，任一项不匹配即停止。同步和验收默认不触发删除。
- `platform create`、`job submit`、审核、授权参考图、取消和删除等 CLI 写操作需要 `--confirm`。`platform sync/open/create` 只连接监听 `127.0.0.1` 的运行中 APP，并调用预加载白名单中的公开方法，不读取页面 Cookie、Token 或存储。

在企业环境部署前，建议配置代码签名、Windows 安装包签名、终端访问控制和应用数据目录备份策略。
